# Aegis Design System

Official color palette, typography, and component specifications for Aegis UI.

## 1. Palette

- **Primary Sky**: `#38BDF8`
- **Primary Strong**: `#0EA5E9`
- **Primary Dark**: `#0284C7`
- **Sky Soft**: `#E0F2FE`
- **Sky Surface**: `#F0F9FF`
- **Dark Background**: `#07111F`
- **Dark Surface**: `#0B1726`
- **Dark Elevated**: `#102235`
- **Text Light**: `#F8FAFC`
- **Muted Text**: `#94A3B8`

## 2. Semantic Colors

- **Success**: Emerald Green (`#10B981`)
- **Warning**: Amber (`#F59E0B`)
- **Danger**: Rose / Red (`#EF4444`)
- **Info**: Sky Blue (`#0EA5E9`)

## 3. Themes

Support for Dark (default), Light, and System modes with zero decorative emoji.
